Behavioral acceptance requires a running current Criterion TV app, as specified by [the product contract](product.md). The isolated `CriterionReferenceTV` AVD uses Google's 1080p television profile. The native emulator's Hypervisor.Framework check passes. Root owns every app input and capture; this establishes reference access, while the behavioral comparison remains incomplete.
