For developers and curious contributors. A consumer install guide will accompany a verified package, its checksums, and its supported-device evidence.

Development checkout↗

Make the work your own.

The repository contains the source, provider research, acceptance requirements, and pinned Docker development tooling.

git clone https://github.com/mikestopcontinues/criterion-webos.git
cd criterion-webos
./dev image

Docker is required. This prepares the development environment; it does not install an app on your TV.

View source ↗ Development guide ↗

Before a TV install

Know the target.

Hardware
Development targets a rooted LG C4 with ARM32 native-app support. Other models are not yet admitted as supported.
Platform
The current target uses webOS SDK 10.3.1. Exact firmware and package compatibility must be verified before installation.
Subscription
Playback will require a valid Criterion Channel subscription and access permitted by the service. This project does not provide content or access.
Package
Use only a release with an explicit device matrix and checksums. No such release has been verified yet.

04 / Built with care

Your screen.
Your trust.

Security and privacy are product requirements. Their implementation—and the licensed playback path—must be verified before account-enabled releases.

A quiet website.

This landing page serves static HTML, CSS, and an original icon. It runs no JavaScript, loads no external fonts, and includes no analytics, account forms, or tracking pixels. GitHub Pages hosts the site; its own service policies apply.

Hosting privacy policy ↗

Credentials stay private.

The app’s requirements include verified TLS, restricted provider origins, bounded requests, secure local session storage, and redacted diagnostics. Account tokens and signed media or license URLs must stay out of Git and issue reports.

Security requirements ↗

Licensed playback only.

Public catalog metadata does not grant viewing rights. The project requires a verified subscriber and licensed platform playback path; it does not bypass DRM. Public routes are undocumented and may change.

05 / Useful answers

Before you
press play.

Open an issue with the exact commit or release, TV model, firmware, and steps to reproduce. Remove personal information, tokens, cookies, and signed URLs first.

Report a reproducible issue ↗
Where is the download?

There is no verified installable release yet. Use the source and development guide to inspect or contribute to the work. Release packages, installation steps, supported devices, and checksums will be published together after acceptance.

Will it work on my LG TV?

The current development target is a rooted LG C4 with ARM32 native-app support. Model, firmware, graphics, input, and DRM compatibility need exact-device evidence. The project does not yet claim support for other LG TVs or installation through the LG Content Store.

Why can’t I sign in or play a film?

Authentication and subscription playback are not yet admitted capabilities. A visible catalog or passing local test does not establish account or DRM support. For immediate viewing, use a supported official Criterion Channel experience.

The development image won’t build. What should I check?

Confirm Docker is running and follow the repository’s development guide from the checked-out source. Include the commit, host architecture, Docker version, failed command, and redacted error when reporting a failure.

Is this an official Criterion app?

No. Criterion Unofficial is an independent project. It is not affiliated with or endorsed by Criterion, Janus Films, JWX, or LG. The software’s license does not grant rights to provider content, artwork, trademarks, or service access.

How is the source licensed?

The project is licensed under GPL-3.0-or-later. Applicable dependency and upstream notices must remain with redistributed software. Contributions and public research belong in the repository; credentials and private device evidence do not.
