For developers and curious contributors. The source and pinned tooling are available now. Consumer installation will follow exact-device acceptance and a verified release.

Development checkout↗

Make the work your own.

The repository contains the source, provider research, acceptance requirements, and pinned Docker development tooling.

git clone https://github.com/mikestopcontinues/criterion-webos.git
cd criterion-webos
./dev image

Docker is required. This prepares the development environment; it does not install an app on your TV.

The development target

Know the target.

Hardware
A rooted LG C4 with ARM32 native-app support is the development target. No TV model has a verified consumer installation yet.
Platform
The pinned SDK and stock SDL/GLES build are documented in the source. Exact firmware, input, graphics, and playback compatibility need TV validation.
Subscription
Viewing films requires a current Criterion Channel subscription and access permitted by the service. This project does not provide content or viewing rights.
Release
There is no verified public IPK release. Supported devices, installation steps, and checksums will accompany an accepted release.

Hosting privacy policy ↗

Credentials stay private.

Provider adapters verify TLS, restrict origins, bound requests, and redact diagnostics. Secure session persistence remains unfinished. Keep tokens, cookies, and signed media or license URLs out of Git and issue reports.

05 / Useful answers

Before you
press play.

Open an issue with the exact commit or release, TV model, firmware, and steps to reproduce. Remove personal information, tokens, cookies, and signed URLs first.

Report a reproducible issue ↗
Where is the download?

There is no verified installable release yet. Use the source and development guide to inspect or contribute to the work. Release packages, installation steps, supported devices, and checksums will be published together after acceptance.

Will it work on my LG TV?

The current development target is a rooted LG C4 with ARM32 native-app support. Model, firmware, graphics, input, and DRM compatibility need exact-device evidence. The project does not yet claim support for other LG TVs or installation through the LG Content Store.

Why can’t I sign in or play a film?

Device-linking state and reviewed subscriber adapters are implemented, but this app’s subscriber integration, secure persistence, and licensed TV playback remain unfinished. For immediate viewing, use a supported official Criterion Channel experience.

The development image won’t build. What should I check?

Confirm Docker is running and follow the repository’s development guide from the checked-out source. Include the commit, host architecture, Docker version, failed command, and redacted error when reporting a failure.

Is this an official Criterion app?

No. Criterion Unofficial is an independent project. It is not affiliated with or endorsed by Criterion, Janus Films, JWX, or LG. The software’s license does not grant rights to provider content, artwork, trademarks, or service access.

How is the source licensed?

The project is licensed under GPL-3.0-or-later. Applicable dependency and upstream notices must remain with redistributed software. Contributions and public research belong in the repository; credentials and private device evidence do not.
